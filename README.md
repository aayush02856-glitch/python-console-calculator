# Python Console Calculator 

My first Python project! A simple console-based calculator built while learning Python. A small step in my coding journey, with many more projects to come!

 Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

 Built With
- Python

 What I Learned
- Python basics
- User input and output
- Conditional statements
- Functions calling and defination
- Basic arithmetic operations

 How to Run
1. Clone this repository.
2. Open the project folder.
3. Run the following command:
python calculator.py
